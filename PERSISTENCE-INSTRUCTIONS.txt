NEXT FILE SET: EXPLICIT SAVE/LOAD FOR THE PREVIOUS RAM FILESYSTEM

Extract these files into the filesystem source directory supplied earlier.
This update targets the exact fs.c/fs.h/shell.c/Makefile from that bundle,
not any unrelated repository or unverified codebase.

Run on the build computer:
  python3 apply_persistence.py
  make clean
  make run

The patch validates expected source markers before writing and preserves
.backup-style copies named *.before-persistence. Inspect the changes before
building. Keep backups outside the project as well.

New modules:
ata.c/.h: minimal primary-master legacy ATA PIO sector access.
fs_persistence.inc: snapshot serialization and save/load functions.
create_disk.py: creates disk.img without overwriting an existing image.
apply_persistence.py: integrates the update into fs.c, fs.h, shell.c, Makefile.

Inside the rebuilt kernel:
  mkdir /Documents
  touch /notes.txt
  write /notes.txt Hello
  mv /notes.txt /Documents/
  save
  halt

Close QEMU and run make run again, then enter:
  load
  cat /Documents/notes.txt
  mv /Documents/notes.txt /
  save

Moving out of a folder changes the destination to / or .. as appropriate.
Existing destination files remain protected against overwrite.

IMPORTANT LIMITATIONS
- Save and load are explicit; no automatic save or load at startup.
- load replaces the live RAM filesystem and resets current directory to /.
  Save any needed work before loading an older snapshot.
- Snapshot data goes to disk.img, a separate emulator disk on the host.
- No GitHub access, USB exchange, FAT/ext4 filesystem, host-folder sharing,
  partitions, or installation on a physical disk is implemented.
- NEVER attach a real drive to this code. It writes sector zero onward.
- QEMU target only: legacy primary-master IDE ATA PIO, not SATA AHCI/NVMe.
- Snapshot format depends on the exact node layout/build; not portable.
- Checksum detects some corruption; it is not authentication or encryption.
- No power-loss atomicity: interruption during save can destroy the previous
  snapshot. Back up disk.img when QEMU is closed.
- Security, recovery, automatic persistence, and general hardware support
  remain unfinished. This is development source, not a finished OS.
- See VERIFICATION.txt for what was and was not tested.
